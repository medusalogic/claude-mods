# claude-mods

Claude Mod Ideas

Mods for Claude Code and the Claude desktop app. Each folder is one mod, and this repository is
the marketplace that lists them.

## Mods

| Mod | What it does |
| --- | --- |
| [session-notes](session-notes) | Session stats in a band above the prompt, and a notes side panel |

## Install

In a terminal session, add a mod by name:

```
/plugin install session-notes --marketplace medusalogic/claude-mods
```

Answer `y` to add the marketplace, then choose a scope. Each mod's folder has its own README with
its commands and settings.
